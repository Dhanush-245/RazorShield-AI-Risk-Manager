# Security policy

RazorShield AI is a defense-only demonstration and is not approved for processing
real payment, identity, or merchant data.

Please report suspected vulnerabilities privately through GitHub's security
advisory feature for this repository. Do not include production credentials,
personal data, or live payment information in an issue.

See [the security architecture and deployment requirements](docs/SECURITY.md) and
[the responsible-agent boundary](docs/AGENT_POLICY.md) for implemented controls,
known limitations, and production gates.
