# Safety

RazorShield is defense-only. It detects and explains observed risk, retrieves trusted merchant policies, recommends bounded defensive review, and records human decisions. It does not teach evasion, invent evidence, assert that anomaly equals fraud, or permit the agent to execute financial actions.

Investigation output separates stored facts, model-supported inferences, recommendations, missing information, and limitations. Retrieved text is treated as context rather than authority; tool names are allowlisted in code. High-impact action remains outside the agent and requires an authorized human and downstream payment controls.
